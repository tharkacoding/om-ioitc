For a query, let AAA be the set of 000's, BBB be the set of 111's, and CCC be
the set of ???'s. By Pigeonhole principle, min⁡{A,B,C}≤6\min\{A,B,C\}\le 6min{A,B,C}≤6, and I claim we
can answer queries in O(2min⁡{A,B,C})\mathcal{O}(2^{\min\{A,B,C\}})O(2min{A,B,C}).

If a query has ∣C∣≤6|C|\le 6∣C∣≤6, we can brute force over all the subsets with 0's at A
and 1's at B. Since there are 2∣C∣2^{|C|}2∣C∣ subsets, this takes
O(2∣C∣)\mathcal{O}(2^{|C|})O(2∣C∣) operations.

Otherwise, we can answer queries with the principle of inclusion-exclusion.
The answer is simply ∑a∈Asuper[B∣a](−1)∣a∣\sum\limits_{a\in A} super[B | a] (-1)^{|a|}a∈A∑​super[B∣a](−1)∣a∣, which we
can calculate in O(2∣A∣)\mathcal{O}(2^{|A|})O(2∣A∣).
